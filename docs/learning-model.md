# Learning model and curriculum specification

The full roadmap follows the supplied 71-module sequence: Python fundamentals → files/CSV/JSON/notebooks → NumPy → pandas selection/transformation/cleaning/joins → EDA → visualization → statistics → SQL/Excel/API → reproducible analytics → final e-commerce project.

Levels remain 0 Absolute Beginner, 1 Python Basics, 2 Python for Data, 3 NumPy Beginner, 4 Pandas Beginner, 5 Data Cleaning, 6 EDA, 7 Visualization, 8 Statistics, 9 SQL + Python, 10 Junior curriculum. A level in a lesson describes material, not the learner's job readiness.

No lesson is locked. Recommended order is the order in the catalog. Lesson completion is a reading acknowledgment. Distinct successful challenge submissions establish practical progress. Quiz feedback includes the learner answer, correct answer, option-specific explanation, correct reasoning, example and related lesson. Wrong answers are retained.

Skills use 30% latest per-question accuracy and 70% distinct challenges passed. Unsupported topics are labelled planned; reading a lesson alone never grants mastery. Review intervals are 0 days after a failure, then 1/3/7/14 days after consecutive correct attempts. The daily set prioritizes due mistakes, then rotates deterministically using the UTC day.
