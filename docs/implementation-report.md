# Отчёт о реализации — Python Data Analyst Academy v0.1

Создано работающее приложение с русскоязычным учебным интерфейсом. Это ранняя версия первой части курса, а не завершённая программа от нуля до Junior. Полный объём исходного ТЗ зафиксирован в curriculum specification и project status; незавершённые функции не помечены готовыми.

## Реализованные возможности

Демо без регистрации, аккаунты с сохранением демо-прогресса, вход/выход, уроки с примерами, квизы с объяснением каждого ответа, повтор ошибок, закладки, практика дня, карта навыков, редактор Python/SQL, форматирование, сохранение черновика, три подсказки и решение по запросу. Таблицы сортируются и листаются. Matplotlib/Seaborn исполняются по-настоящему и возвращают PNG. Есть тёмная/светлая темы и мобильная навигация.

Прогресс хранится в PostgreSQL; SQLite используется в разработке. У попыток сохраняется версия контента. Черновики и самостоятельные проектные чеклисты хранятся в браузере. Запуск видимого примера не засчитывает задачу; полная проверка проверяет альтернативные данные и только затем обновляет прогресс.

## Объём и библиотеки

12 уроков, 60 вопросов, 15 исполняемых задач, 4 проектных брифа с CSV-архивами и словарями данных, 7 наборов тематического повторения. Восемь сгруппированных областей: Python, NumPy, pandas, очистка/объединение, EDA, визуализация, статистика, SQL.

- Python: первая программа, переменные, типы, условия, функции, коллекции и обработка ошибок на вводном уровне.
- NumPy: массивы, маски, векторизация, shape/axis, broadcasting и NaN; задача с возвращаемым ndarray.
- pandas: выбор, фильтрация, сортировка, новые колонки, groupby, именованные агрегации, пропуски, дубликаты, строки, вводные примеры merge/datetime.
- Matplotlib: месячный график, Figure/Axes, подписи; проверяются данные линии на других месяцах и значениях.
- Seaborn: объяснение выбора графиков и настоящий histogram в playground; отдельного полного оцениваемого трека нет.
- Статистика: среднее/медиана, выбросы, выборка, ddof, p-value, абсолютный и относительный uplift; вводный пример SciPy. Это не завершённый курс A/B-тестирования.
- SQL: SQLite, SELECT/WHERE/GROUP BY/HAVING/ORDER BY, SQL+pandas, параметризация; запрос проверяется на альтернативных таблицах.
- openpyxl доступен в среде исполнения; самостоятельный Excel/API трек пока не создан.

## Структура и архитектура

`academy/` — FastAPI, SQLAlchemy, контент, генераторы данных и доверенный grading. `runner/` — закрытый broker, Docker launcher, протокол и недоверенный worker. `frontend/` — React/TypeScript, CodeMirror, Nginx, Vitest и Playwright. `content/` — версионированный каталог и JSON Schema. `migrations/` — Alembic. `scripts/` — авторинг, валидация, экспорт схем и полный verification. `tests/` — API, grading, datasets, protocol и sandbox security. `docs/` — спецификации, threat model, инструкции и скриншоты. `.github/workflows/` — CI.

Поток исполнения: браузер → Nginx → FastAPI → приватный broker → новый Docker-контейнер на каждый набор данных → ограниченный JSON → доверенная эталонная функция и сравнение → обратная связь и БД. Эталонные ответы не находятся в learner-контейнере. Проверяются новые категории, порядок строк, дробные значения, пропуски, дубликаты, увеличенные наборы и другие периоды, где это применимо к контракту.

Контейнеры ученика работают без сети, root, host mounts и Docker socket, с read-only root, ограничениями CPU/памяти/PID/вывода/времени. Сам broker обладает Docker-socket authority и должен оставаться приватным. Это локальная конфигурация; изоляция контейнером не является доказательством защиты от всех атак. Подробности и остаточные риски — в `code-runner-security.md`.

## Проверки и ограничения

Фактические команды, результаты тестов, E2E и Docker отражены в `verification.md`. Скриншоты сняты в реальном приложении. Ключевой сценарий доказывает, что подогнанный под пример ответ отклоняется скрытыми проверками, а общее решение принимается и сохраняется.

Итоговые результаты: 57 Python-тестов, 2 frontend-теста и 3 Playwright-сценария прошли; сборка Docker из чистого клона и оба задания GitHub CI прошли. [Публичный репозиторий](https://github.com/German4341374/python-data-analyst-academy) создан с указанными в ТЗ темами. Известных уязвимостей по выполненным аудитам Python/npm не найдено.

До полной версии остаются 40+ проработанных уроков / 200+ разнообразных вопросов / 70+ задач, все 71 модуль в требуемой глубине, независимые экзамены, оценивание четырёх проектов и финальная работа на неизвестном наборе данных. Текущие семь повторений используют вопросы уроков. Публичные генераторы не являются секретами для экзамена; проверка мутаций внутри интерпретатора не защищена от целенаправленной подмены. Нет восстановления пароля, email verification, произвольной загрузки пользовательских данных и готовой эксплуатации как публичного многопользовательского сервиса.

MIT выбран для простого образовательного переиспользования. Данные синтетические. Гарантий трудоустройства или подтверждения уровня Junior приложение не выдаёт.
